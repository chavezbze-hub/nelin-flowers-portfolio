# Nelin Flowers — Social Work Portfolio

This repository contains Nelin Flowers’ professional portfolio and résumé.

## Portfolio

Open [index.html](index.html) to view the portfolio. It includes:

- A professional introduction and internship / B.S.W. field-placement focus
- A visual education and professional-growth timeline
- Reflections on all nine CSWE 2015 EPAS social work competencies
- Licensure preparation and post-graduation action planning
- An advanced-studies action plan
- A reflective undergraduate goal-attainment snapshot
- Professional qualities, experience, ethics, and standards of conduct

## Résumé

Select **Download résumé** from the portfolio to open [Nelin-Flowers-resume.html](Nelin-Flowers-resume.html). The résumé is self-contained and print-friendly.

The portfolio uses web fonts when internet access is available and includes system-font fallbacks for offline viewing.
